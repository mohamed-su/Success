Instructions d'Intégration

Pour intégrer dans votre interface rapporteur existante :

  1. Ajoutez le script : Incluez le fichier replace-evaluation-form.js dans votre page
  2. Remplacement automatique : Le script remplace automatiquement tous les boutons "Évaluer" par "Délibérer"
  3. Nouveau formulaire : Le formulaire est basé exactement sur le document officiel de délibération
  4. Sauvegarde : Les données sont envoyées vers l'endpoint /api/rapporteur/protocols/{id}/decision

⚠️ Important :

Assurez-vous d'exécuter le script SQL add_deliberation_columns.sql pour ajouter les nouvelles colonnes à la base de données.

Vous pouvez utiliser le fichier update-database.bat pour cela.
